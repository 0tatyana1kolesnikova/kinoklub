# Киноклуб

Статический сайт с одним видео. Подготовлен для размещения на GitHub Pages. Видео разбито на части, которые страница собирает в браузере перед просмотром; сборка требует загрузить весь файл и может занять время. Суммарный размер ролика около 130 МБ.

Для проверки локально нужен HTTP-сервер: открытие файла index.html двойным щелчком может не позволить загрузить части видео. Например, при установленном Node.js из папки сайта можно выполнить `npx serve .`, затем открыть показанный адрес.

Для публикации загрузите содержимое папки в репозиторий, сохранив подпапку `videos` и имена файлов. В настройках репозитория Settings → Pages выберите Deploy from a branch, ветку main и папку / (root). Публикация на публичном GitHub Pages делает все файлы, в том числе видео, доступными посетителям.

Кнопка «Открыть свой файл» открывает его только у текущего посетителя. Для добавления общих видео необходимо обновить файлы репозитория и список videos.js; загрузка из браузера на общий сервер здесь не реализована. Для удобной общей видеотеки с кнопкой загрузки нужно отдельно подключить сервер и хранилище.
