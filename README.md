# Киноклуб

Статический сайт для GitHub Pages. Видео подготовлено для воспроизведения по мере загрузки и хранится в `videos/stan-stream.mp4`. Список общих видео находится в `videos.js`.

Кнопка «Открыть свой файл» открывает его только у текущего посетителя. Для добавления общих видео необходимо обновить файлы репозитория и список `videos.js`; загрузка из браузера на общий сервер здесь не реализована. Для удобной общей видеотеки с кнопкой загрузки нужно подключить сервер и хранилище.
